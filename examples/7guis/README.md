# 7 GUIs (cosuous)

An implementation of the [7 GUIs](https://eugenkiss.github.io/7guis/) tasks
(counter, temperature converter, flight booker, timer, CRUD, circle drawer,
cells) built with [cosuous](https://jsr.io/@usagi-computer/cosuous).

## Run

```sh
deno task dev      # start the Vite dev server
deno task build    # production build to dist/
deno task preview  # preview the production build
```
